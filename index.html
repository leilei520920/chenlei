域名与 DNS

子域名没有独立 WHOIS，要查根域

注册了一个免费三级域名，想知道它能活多久，查子域名什么也查不到。真正决定生死的是根域：whois de5.net 看注册局到期日。根域一过期，底下所有子域一起消失，而这一步你完全控制不了。

判断一个后缀还活着，看 SOA 不看 ping

nslookup -type=SOA example.com 能返回主 NS 和序列号，说明注册局在正常提供权威数据；ping 不通只代表没配 A 记录，说明不了什么。有的后缀 root 还在、子域却早已停服，SOA 是更靠谱的第一道筛子。

PSL 决定这个域名能不能当独立站

不在公共后缀列表（PSL）里的免费后缀，浏览器会把所有用户的 Cookie 混在一起，Cloudflare 之类也没法按整域托管。判断方法只有一条：拉官方 public_suffix_list.dat 逐行 grep，别信服务商自己的宣传页。

下载失败时 grep 会安静地骗你

用 grep -qx 核对域名是否在多行文件里，如果那个文件其实没下载成功，它会返回「不匹配」而不是报错 —— 于是得出一整批域名都不在列表里的假结论。核对前先确认文件行数和字节数。

GitHub Pages

一个仓库只能绑一个自定义域名

三个域名都指向同一个站点时，只有最后设置的那个能拿到证书，其余会报证书错误。要让多个域名同时可用，得拆成多个仓库分别配 Pages，不是加条解析就能解决。

CNAME 文件是绑定凭据，删了站点就掉线

设置自定义域名后 GitHub 会往仓库里提交一个 CNAME 文件。它看起来像个无关紧要的配置，实际是 Pages 判断该服务哪个域名的依据。

改自定义域名会新增一条用真实邮箱署名的提交

这条自动提交的作者邮箱绕不过账号的隐私设置，公开仓库里任何人翻历史都能看到。改完域名记得回头查一眼 git log --format="%ae"。

浏览器自动化

React 受控表单：改 value 不等于改状态

直接赋值 input.value 页面显示变了，提交时却是空的。要走原生 setter 再派发 input 事件：Object.getOwnPropertyDescriptor(HTMLInputElement.prototype,'value').set.call(el, v)。

视口外的按钮点不中，滚动不一定管用

某些布局下 window.scrollTo 会被还原，scrollIntoView 也不生效。可靠的解法是把视口高度调大（调试协议里的 Emulation.setDeviceMetricsOverride），让目标进入可视区再点。
